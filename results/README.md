# Results

- `figures/` — generated plots (accuracy/latency/energy comparisons,
  noise-robustness curves).
- `tables/` — generated CSV/Markdown tables, including
  `tables/jetson_bench/` (raw on-device benchmark logs).
- `reports/` — the performance report and power/energy comparison
  deliverables named in `docs/praxis/00-scope-of-work.md`.

Bulk outputs are gitignored; keep small representative samples committed
so the repo stays reviewable without needing a full pipeline re-run.
